# Finance Agent

## Overview
- Handles finance-domain interactions in Saarthi AI.
- Uses Gemini prompt-to-tool selection and executes finance actions.
- Stores/retrieves expenses from DB and optionally writes to Google Sheets.

## Responsibilities
- Interpret finance intent from message via Gemini model.
- Save expense entries.
- Return last expense.
- Return category summary.
- Return total/weekly spending and high-spend warning.
- Trigger asynchronous Gmail expense sync helper.

## Inputs
- Runner: `run_finance_agent(message: str, user_id: str)`.
- Tool arguments generated by model JSON (`tool`, `args`), including:
- `amount`, `category`, `description` for save flow.
- `user_id` is threaded into DB read/write closures.

## Outputs
- Returns `AgentResponse` (`db/schemas.py`) with:
- `status=ok` for executed tool
- `status=partial` for non-finance/unknown tool/parse fallback
- `status=error` for uncaught exceptions
- `data` includes selected tool and arguments on success

## Internal Flow
- Configure Gemini with `GEMINI_API_KEY`.
- Prompt model to produce exactly one JSON tool call.
- Parse response JSON.
- If `tool=none` or missing tool -> partial response.
- Dispatch to local tool map:
- `save_expense`
- `get_last_expense`
- `get_spending_summary`
- `get_weekly_spending`
- Return `AgentResponse` with summary from tool output.

## Dependencies
- LLM: `google.generativeai`.
- DB helpers: `db/finance_db.py` (`insert_expense`, `get_all_expenses`).
- Sheets API: `gspread`, `google.oauth2.service_account.Credentials`.
- Schemas: `db/schemas.py`.
- Gmail sync helper: `tools/gmail_mcp.py` (via `sync_gmail_expenses`).
- Local credential file: `credentials.json`.

## Example Usage
- API path in `main.py`: `POST /finance/chat`
- Example body:
- `{"message":"I spent 450 on lunch","user_id":"00000000-0000-0000-0000-000000000001"}`

## Current Status
- Partial.

## Limitations
- Relies on model-generated JSON; no strict schema validation beyond basic parse.
- Uses synchronous DB helpers inside async runner.
- `_get_sheet()` depends on local `credentials.json` and spreadsheet name `expenses_sheet`.
- `sync_gmail_expenses` is not integrated into `run_finance_agent` request flow.
- `main.py` also contains conflicting Flask-style finance route code (`run` import, `request/jsonify`) that does not match FastAPI usage.

## Future Improvements
- Add robust JSON schema validation for tool selection.
- Migrate DB helpers to async APIs for consistency.
- Normalize credential/config handling via env variables.
- Add deterministic parser path for common expense utterances.
- Add unit tests for each tool path and failure mode.
